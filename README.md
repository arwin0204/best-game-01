# LUMEN BLOOM

A neon garden defence arena shooter built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## What it is

LUMEN BLOOM is a fast arena shooter set in a glowing neon garden. Defend the bloom, dodge and shoot through waves of enemies, and chase the high score. The game runs entirely in the browser — no build step, no server.

## Run it

```sh
npx serve .
```

Then open http://localhost:3000 and play. The entrypoint is `main.ts`, served by `serve.ts`.
